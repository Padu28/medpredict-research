# Data Card — MedPredict Synthetic Readmission Cohort

> ⚕️ Synthetic data for education. Contains **no** real patient information.

| Field | Value |
|---|---|
| **Generator** | `src/medpredict/data/cohort.py` (seeded, deterministic) |
| **Cohort** | ≈6 000 synthetic adults, 1–3 hospital discharges each (≈11 000 encounters), 2022–2025 |
| **Sites** | A (45 %), B (35 %), C (20 %) — C has older, more diabetic case-mix and sparser HbA1c coding |
| **Target** | `readmit_30d` — unplanned readmission within 30 days of discharge |
| **Prediction time** | Discharge. Only information available at or before discharge is allowed. |
| **Unit of analysis** | Encounter; **split unit is the patient** |
| **Licence** | MIT (generated by this repository) |

## Features
Age, sex, BMI, systolic BP, glucose, HbA1c, creatinine, haemoglobin, length of stay, prior admissions
(12 months), medication count, admission type, smoking status, discharge disposition.

## Deliberate data issues (for teaching)
| Issue | Purpose |
|---|---|
| `followup_calls_30d`, `readmission_cost` (post-outcome) | Leakage detection — excluded, enforced by tests |
| HbA1c missing for ≈35 % of site-C encounters | Data-collection shift; missing-indicator artefacts |
| Prevalence rises over time | Temporal shift between train and test periods |
| Site C higher baseline risk | Site-transfer calibration failure |

## Split
Temporal + patient-level: a patient belongs to the split of their **first** discharge
(train ≤ 2024-06-30 < validation ≤ 2025-03-31 < test). No patient appears in two splits.

## Alternative datasets
* `source: breast_cancer` — scikit-learn's bundled Wisconsin Diagnostic data (classification/calibration practice; no subgroups).
* UCI Heart Disease / Diabetes 130-US hospitals — place a CSV in `data/raw/` and set `source: csv`.
* MIMIC-IV — requires credentialing and a data-use agreement; never commit it.

## Limitations
Synthetic relationships are simpler than clinical reality; results carry **no** clinical meaning.
